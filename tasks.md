# Tasks: Реализация мини-трекера

## 1. Основная реализация

- [ ] Создать выбранную структуру файлов варианта A или B.
- [ ] Реализовать модель задачи: id, title, hours, done.
- [ ] Реализовать стартовый набор задач.
- [ ] Реализовать добавление задач.
- [ ] Реализовать удаление задач.
- [ ] Реализовать переключение done.
- [ ] Реализовать валидацию названия.
- [ ] Реализовать валидацию часов.
- [ ] Реализовать сохранение введённых значений при ошибке.
- [ ] Реализовать отображение ошибок рядом с полями.
- [ ] Реализовать фильтр «Все».
- [ ] Реализовать фильтр «Активные».
- [ ] Реализовать фильтр «Готовые».
- [ ] Реализовать расчёт суммарных часов.
- [ ] Реализовать расчёт выполненных часов.
- [ ] Реализовать расчёт прогресса.
- [ ] Реализовать обработку пустого списка.
- [ ] Реализовать адаптивный интерфейс шириной 390 px.
- [ ] Добавить подписи полей и кнопок.
- [ ] Обеспечить автономность без CDN, внешних библиотек
      и API-ключей.

## 2. Необязательное улучшение

- [ ] Реализовать сохранение задач в localStorage.
- [ ] Реализовать восстановление задач.
- [ ] Обработать недоступность localStorage.
- [ ] Обеспечить продолжение работы в памяти.
- [ ] Отобразить сообщение о недоступности хранилища.

## 3. Приёмочные проверки

### Данные и операции

- [ ] Добавление корректной задачи.
- [ ] Удаление задачи.
- [ ] Переключение done в true.
- [ ] Переключение done в false.

### Валидация

- [ ] Пустое название блокирует добавление.
- [ ] Название из пробелов блокирует добавление.
- [ ] Пустые часы блокируют добавление.
- [ ] Отрицательные часы блокируют добавление.
- [ ] Значение ниже 0.5 блокирует добавление.
- [ ] Значение выше 24 блокирует добавление.
- [ ] Значение с недопустимым шагом блокирует добавление.
- [ ] Ошибка отображается рядом с полем.
- [ ] Значения формы сохраняются при ошибке.

### Расчёты

- [ ] Начальные часы равны 8.
- [ ] Начальные выполненные часы равны 2.
- [ ] Начальный прогресс равен 25%.
- [ ] После выполнения «Практики» выполнено 6 из 8 часов.
- [ ] После выполнения «Практики» прогресс равен 75%.
- [ ] При удалении всех задач итог равен 0 ч.
- [ ] При удалении всех задач прогресс равен 0%.
- [ ] NaN и Infinity не отображаются.

### Фильтры

- [ ] Фильтр «Все» отображает все задачи.
- [ ] Фильтр «Активные» отображает только незавершённые.
- [ ] Фильтр «Готовые» отображает только завершённые.
- [ ] Фильтр не изменяет исходные данные.
- [ ] Фильтр не изменяет суммарные часы.
- [ ] Фильтр не изменяет прогресс.
- [ ] При фильтре «Активные» начальный прогресс остаётся 25%.

### Интерфейс

- [ ] Интерфейс читаем при ширине 390 px.
- [ ] Горизонтальная прокрутка отсутствует.
- [ ] Поля имеют понятные подписи.
- [ ] Кнопки имеют понятные подписи.

### Автономность

- [ ] Приложение не использует CDN.
- [ ] Приложение не использует внешние библиотеки.
- [ ] Приложение не требует API-ключей.

### Необязательное сохранение

- [ ] Проверить восстановление данных после перезапуска.
- [ ] Проверить поведение при недоступности localStorage.
- [ ] Проверить продолжение работы в памяти.
- [ ] Проверить сообщение о недоступности хранилища.

## 4. Статус проверок

### Фактически проведённые проверки

- Спецификация подготовлена в текстовом виде.
- Реализация не выполнялась.
- Проверки приложения не проводились.
- OpenSpec CLI не запускался.
- OpenSpec-валидатор не запускался.
- Браузерное тестирование не проводилось.

### Предложенные проверки

Все проверки, перечисленные в разделе 3, являются
предложенными проверками реализации и приёмки.
